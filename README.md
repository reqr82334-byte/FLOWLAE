# FLOWLAE

Адаптивная витрина сервиса выкупа и доставки товаров из Китая.

## Реализовано
- Премиальный молочно-белый, графитовый и приглушённо-золотой дизайн.
- Адаптивная навигация, каталог с фильтрами и модальная форма.
- Ссылки на Telegram: https://t.me/FlowLAE и https://t.me/FlowLAv.

## Важно
Каталог содержит демонстрационные категории, а не реальные товары и цены. Форма пока не отправляет данные на сервер. Не вводите реальные персональные данные до подключения backend.

## Следующий этап
1. Backend API и PostgreSQL для товаров, пользователей и заказов.
2. Telegram-бот администратора для управления каталогом и статусами заказов.
3. Отправка заявок и защищённая загрузка подтверждения оплаты.
4. Ручное подтверждение СБП.
5. Деплой сайта и постоянно работающих API/бота.

Секреты и токены хранить только в переменных окружения на сервере. Не коммитить файлы с реальными секретами.
