# FLOWLAE

Адаптивная витрина и начальная основа системы выкупа и доставки товаров из Китая.

## Frontend
- Премиальный молочно-белый, графитовый и приглушённо-золотой дизайн.
- Адаптивная навигация, демонстрационный каталог и фильтры.
- Форма на витрине пока демонстрационная и не отправляет заявки в API.

## Backend API
Начальная версия на FastAPI + SQLAlchemy: публичный просмотр активных товаров, создание заказа через API, защищённое управление товарами, просмотр заказов и изменение статусов администратором.

Локальный запуск: перейти в backend, создать виртуальное окружение Python, установить зависимости командой pip install -r requirements.txt, скопировать .env.example в .env и задать ADMIN_API_KEY, затем запустить uvicorn app.main:app --reload.

Документация API: http://127.0.0.1:8000/docs. По умолчанию используется SQLite; для PostgreSQL задайте DATABASE_URL.

## Telegram admin bot
Начальная версия бота умеет показывать заказы и товары, добавлять/редактировать/скрывать/удалять товары и менять статусы заказов.

Локальный запуск: перейти в bot, установить зависимости pip install -r requirements.txt, скопировать .env.example в .env, задать BOT_TOKEN от BotFather, числовой ADMIN_TELEGRAM_ID, API_BASE_URL и тот же ADMIN_API_KEY, затем запустить python main.py.

## Статусы заказов
awaiting_payment → paid → purchased → at_warehouse → shipped → delivered.

## Что ещё не подключено
- Форма сайта пока не создаёт заказ в API.
- Нет загрузки чека, ручного подтверждения оплаты и настройки реквизитов СБП.
- Нет клиентского личного кабинета и публичного отслеживания заказов.
- Не настроены уведомления клиентам и production-деплой.
- Начальная версия API и бота ещё требует локального тестирования перед запуском для клиентов.

## Безопасность
Реальные токены, пароли, API-ключи, реквизиты и персональные данные не добавлять в GitHub. Используйте локальные .env и секреты хостинга. Не публикуйте Telegram bot token в переписке.
